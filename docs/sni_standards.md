## 1. Standar Briket Biomassa (SNI 01-6235-2000)

Standar Nasional Indonesia (SNI 01-6235-2000) menetapkan kriteria mutu briket arang dan biomassa padat:

| Parameter Uji | Satuan | Syarat Mutu SNI | Batasan pada GlagahSmart |
| :--- | :--- | :--- | :--- |
| **Kadar Air (*Moisture Content*)** | % | Maksimal 8.0% | Toleransi bahan mentah: $\le 12.0\%$ |
| **Kadar Abu (*Ash Content*)** | % | Maksimal 8.0% | Verifikasi via uji muffle furnace |
| **Zat Terbang (*Volatile Matter*)** | % | Maksimal 15.0% | Diuji pada suhu 950°C |
| **Nilai Kalor (*Calorific Value*)** | kal/g | Minimal 5.000 kal/g | Target biomassa: $\ge 4.000\text{ kal/g}$ |
| **Kadar Karbon Terikat** | % | Minimal 77.0% | Menentukan efisiensi bara api |

> **Catatan Implementasi:**
> Partikel serbuk rontokan bunga glagah (*chaff*) memiliki rasio luas permukaan terhadap volume yang sangat baik untuk pembriketan tanpa memerlukan perajangan ulang. Penambahan perekat tapioka sebesar 5-8% b/b direkomendasikan untuk stabilitas mekanis.

## 2. Standar Kematangan Kompos Organik (SNI 19-7030-2004)

Standar Nasional Indonesia (SNI 19-7030-2004) mengenai spesifikasi kompos dari bahan organik:

| Parameter | Standar SNI 19-7030-2004 | Relevansi Residu Glagah |
| :--- | :--- | :--- |
| **Kadar Air** | 10% – 50% | Residu basah (30-55% MC) sangat ideal untuk memulai dekomposisi aerobik. |
| **Suhu** | Sesuai suhu air tanah | Memerlukan fase termofilik ($55^\circ\text{C}-65^\circ\text{C}$) untuk membunuh patogen. |
| **Nilai pH** | 6.80 – 7.49 | Residu glagah bersifat netral-sedikit asam (pH 6.2 - 6.8). |
| **Rasio C/N** | 10 – 20:1 | Glagah kaya selulosa (C tinggi, C/N ~ 40:1), perlu dicampur kotoran ternak (N tinggi). |
| **Bahan Asing** | Maksimal 1.5% | Residu glagah bebas dari plastik dan logam. |

## 3. Aturan Pengujian Benih (ISTA Rules 2023)

Berdasarkan pedoman *International Seed Testing Association* (ISTA):
1. **Uji Perkembangan Standar (*Standard Germination Test*):**
   - Media: Kertas saring lembap (*Top of Paper* / TP).
   - Suhu inkubator: $25^\circ\text{C}$ konstan atau $20^\circ\text{C}/30^\circ\text{C}$ berkala.
   - Durasi evaluasi: Hari ke-7 (evaluasi pertama) dan hari ke-14 (evaluasi akhir).
2. **Uji Tetrazolium (*TZ Viability Test*):**
   - Larutan 2,3,5-triphenyl tetrazolium chloride 1.0%.
   - Pewarnaan merah pada embrio menunjukkan respirasi enzimatis aktif (benih hidup/viabel).
